# TPS Studios

Le lanceur des projets TPS Studios pour OMSI 2 / openOMSI.

## ⬇️ [Télécharger le lanceur TPS Studios](https://github.com/Dreams9972/TPS-Studios/releases/latest/download/TPS.Studios.exe)

1. Téléchargez **TPS.Studios.exe** et lancez-le. Il crée un raccourci « TPS Studios » sur le bureau.
2. Choisissez un projet dans la bibliothèque, puis cliquez sur **INSTALLER**.
3. Les mises à jour arrivent toutes seules : le bouton devient **METTRE À JOUR**. Ensuite, cliquez sur **JOUER**.

Windows peut afficher « Windows a protégé votre ordinateur », car le lanceur n'est pas signé. Cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.

## Projets

- **ParisView** : le métro de Paris, lignes 3bis (MF 67) et 7bis (MF 88). C'est une carte d'expérience en bêta, qui ne cherche pas à reproduire la réalité à 100 %.

Il faut OMSI 2 et openOMSI.
